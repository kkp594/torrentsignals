🧪 Strategy Backtester

Test any screener strategy on historical data to see if it actually works.


How it works:

1. Pick a preset strategy (or use current screener filters)

2. For each day in history, runs the screener

3. Simulates: buy at next open, hold N days, sell at close

4. Shows win rate, avg return, best/worst symbols


Uses cached yfinance data. First run downloads ~50 symbols and may take 60-90s.
