⚡ Upstox API Credentials

How to set up:
1. Go to developer.upstox.com → Create App
2. Set Redirect URL to http://localhost:8765/callback
3. Copy API Key and Secret Key → paste below → Save
4. Each morning: get Daily Access Token from Upstox and paste below
5. Token expires at midnight — paste fresh token next morning

🦁 Shoonya (Finvasia) Credentials

Where to find your credentials (prism.shoonya.com):
1. Go to prism.shoonya.com → log in → click API Key (top right)
2. You will see:
  • Client Id (e.g. FA107850_U) → paste into Client Id below
  • Secret Code (long key) → paste into Secret Code below
3. URL / IP Address fields in PRISM → leave blank, not needed
4. MPIN = the PIN you use in the Shoonya mobile app (usually 4–6 digits)

📋 stocks.csv Format Guide

Location: D:\sApp\assets\stocks.csv

Supported columns:

SYMBOL — Stock symbol (required). Use NSE symbol by default.

EXCHANGE — Optional. Set to BSE for BSE-only stocks, leave blank for NSE.

Example:

SYMBOL,EXCHANGE
RELIANCE,NSE
HDFCBANK,NSE
ANANTRAJ,NSE
MTARTECH,NSE
SOMEBSESTOCK,BSE

If EXCHANGE column is missing, NSE is assumed. The app auto-tries BSE (.BO) if NSE has no data.

🛡 Daily Profit Guard

Why this feature?
You earn good profits early in the session, then give them all back due to greed or overtrading. Profit Guard stops that cycle. Once your daily target is reached, it intervenes — soft warning, cooling-off period, or hard lock — so you walk away with the money you made.
Disabled
Enable daily profit target protection
Guard activates when your realised P&L reaches or exceeds this amount

⚙ Protection Level

Choose how aggressively to protect your profits when the daily target is reached. All levels are completely optional and can be changed anytime.

Level 1 Soft Warning ✓

Displays a full-screen warning overlay with your daily stats and motivational message. You can still choose to continue — but you have to consciously acknowledge the risk.

Level 2 Cooling-Off Mode ✓

Blocks new trade entry for a mandatory cooling-off period. After the timer expires you can resume, but you'll see the warning first.

Level 3 Hard Lock ✓

Prevents any new positions until you manually unlock by clicking the confirmation button the required number of times — making you deliberately acknowledge the risk.

ℹ How It Works

1. Set your daily profit target (e.g. ₹2,000) and choose a protection level.

2. In your Pro Trading Terminal app, the guard checks your realised P&L automatically.

3. When the target is reached, the guard fires:

Level 1: Full-screen overlay with statistics and choices — Stop, Take a Break, or Continue.
Level 2: Same overlay + trading is blocked for your chosen cooldown period.
Level 3: Same overlay + hard lock requiring multiple deliberate unlock clicks.

4. Lock state automatically resets at midnight for the next trading day.

5. You can always use ↺ Reset Today's Lock above if needed.
